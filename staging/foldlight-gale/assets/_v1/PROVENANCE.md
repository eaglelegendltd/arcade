# Asset provenance: Foldlight Gale

All assets in this folder are **original work by Luna (Art & Animation Director) for Eagle Legend LTD**, created 2026-10-13 and updated for ART_NEEDS.md the same day.
No third-party, stock or copyrighted assets were used, and no existing IP was imitated. Every shape is a hand-authored SVG primitive in `/workspace/art_src/gen.py`; PNGs are rendered from those SVGs by code (CairoSVG) at the exact file sizes listed. Text (DejaVu Sans, a free font) appears only on the thumbnail. Rebuild: `/workspace/.venv/bin/python /workspace/art_src/gen.py`.
